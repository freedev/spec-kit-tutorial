# Contributing a New Workshop

Thank you for your interest! To propose a new workshop:

1. Copy `templates/new-workshop-template/` to `workshops/<your-workshop-slug>/` (use kebab-case, include language).
2. Fill in the README and prerequisites.
3. Add your assets and reference solution.
4. Submit a pull request.

See `.github/ISSUE_TEMPLATE/workshop-proposal.md` for the proposal template.
