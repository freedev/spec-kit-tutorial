# Spec Kit Workshops

A collection of hands-on workshops for learning Spec-Driven Development with GitHub Spec Kit.

See `docs/what-is-spec-kit.md` for an overview of Spec-Driven Development.

See `docs/when-to-use-sdd.md` for when SDD is (and isn't) the right tool.

## Available Workshops

| Workshop                   | Language/Stack | Difficulty | Duration | Status  |
|---------------------------|---------------|------------|----------|---------|
| [Number Guessing Game (Java)](workshops/number-guessing-game-java/README.md) | Java/Gradle    | Beginner   | 1 hour   | Beta    |
| [Number Guessing Game (Python)](workshops/number-guessing-game-python/README.md) | Python/uv      | Beginner   | 1 hour   | Beta    |
| [Number Guessing Game (Quarkus/Gemini)](workshops/number-guessing-game-quarkus-gemini/README.md) | Quarkus/Java/Maven | Beginner   | 1 hour   | Beta    |
| [Bookmark Manager REST API (Java)](workshops/bookmark-manager-rest-java/README.md) | Quarkus/Java/Gradle | Intermediate | 3–4 hours | Beta    |

Each workshop has its own prerequisites (see their folders).
